## 1. 오늘 꼭 정할 것 (안 정하면 개발이 막힘)

| # | 안건 | 현재 상태 | 제안 | 결정 |

| 4 | 11/5 오후 결정 승인 | way-on.md **8장에만** 있고 1~7장 본문은 옛 내용 | 8장 승인 → 본문 반영 (아래 1-1) | |
| 5 | 앱 API 초안 | [app-api.md](../app-api.md) 새로 작성 (차 ⇄ 서버 ⇄ 폰 REST·WebSocket). 팀원 미검토 | 큰 틀 승인, 세부는 개발하면서 수정 | |

| 8 | 휴게소 진행 방향 | 반대 차로(건너편) 휴게소를 거르는 값(`travel_bearing`). API에 없음 → 휴게소 seed를 못 만듦 | 시연 구간은 직접 입력, 나머지는 상·하행 좌표로 계산 | |
