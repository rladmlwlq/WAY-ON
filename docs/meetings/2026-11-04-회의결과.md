## 4. 메모에 적힌 질문과 확인 결과

| 메모 | 확인 결과 |
|---|---|
| 앱과 연결하는 방식이 Pleos 안에서 되는지 | 외부 서버 통신은 Pleos 공식 문서가 전제하고 규칙을 둠 → **허용으로 판단**. 조건: HTTPS/WSS(TLS 1.2+), IP 대신 도메인, 토큰은 URL에 넣지 않기, 심사·전시 기간 서버 상시 가동 ([앱 보안 가이드](https://document.pleos.ai/en/docs/pleos-only/app-registration-guide/app-security-guide), [앱 제출 가이드](https://document.pleos.ai/en/docs/pleos-only/distribute/app-submission-guide)) |
| 카카오·TMAP·NAVER 제한 | Pleos는 **자체 내장 내비**이고 NaviHelper는 그 내비만 제어. 동승자 폰은 지도 앱과 연동하지 않고 **우리 웹에 카카오맵 JS SDK로 직접 지도**를 그림. 카카오는 장소 검색(REST)과 지도(JS) 키만 씀 |
| 경로가 설정된 상태에서 검색이 되는지 | NaviHelper에 "경로 주변 검색" 기능은 없음 → 서버가 위치·방향·목적지로 계산 (D5). 남은 거리·시간은 `onDrivingInfo`, ETA·도착 시 배터리는 `requestTrip()`→`onTripInfo`로 받을 수 있음 |
| 도로 법규 확인 | Pleos [운전 제한 정책](https://document.pleos.ai/en/docs/pleos-only/vehicle-app-planning-guide/driving-restiction-policy): **QR sign-in은 모든 지역에서 운전 중 금지**(`UX_RESTRICTIONS_NO_SETUP`). 운전 중 쓰는 앱은 DO(Distraction Optimization) 선언 필요. 한국이 속한 "기타 지역"은 키보드·검색 허용 |
